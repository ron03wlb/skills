# Limit the Canonical Wiki to current behavior

The Canonical Wiki explains current business flows, cross-module interactions, rules, invariants, states, exceptions, roles, permissions, data ownership, and the source-linked technical context needed to understand that behavior.

It links to rather than duplicates the authorities for terminology (`CONTEXT.md`), architectural decisions (ADRs), requirements and change history (Issue Change Specs), API reference, user documentation, and operational runbooks. Agent prompts, engine state, caches, and temporary generation artifacts are not Canonical Wiki content.
