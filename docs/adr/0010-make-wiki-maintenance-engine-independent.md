# Make Wiki maintenance engine-independent

Ron's Issue, Grant, review, and closeout flow is the required Wiki maintenance control plane. It must support reviewed human or agent-authored Markdown without depending on a third-party Wiki engine.

An open-source engine may later be adopted as an optional, replaceable patch proposer. Adoption requires a separate authorized Issue that verifies an exact version, installation, bounded generation, incremental updates, citation drift, lint and build behavior, and a real Parent or Standalone closeout.

No engine is selected or verified by this decision.
