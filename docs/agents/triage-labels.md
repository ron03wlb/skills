# Triage Labels

The skills use five canonical triage roles. This repository uses the same string for each GitHub label.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and executable by an agent |
| `ready-for-human` | `ready-for-human` | Human implementation or decision is required |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a canonical role, apply the corresponding tracker label from this table.
