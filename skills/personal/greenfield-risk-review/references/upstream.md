## Reusable Guidance

Examine:

- demand: a specific user or buyer has an urgent problem;
- positioning: the user can understand the value in one sentence;
- monetization or strategic value: a credible budget or organizational benefit exists;
- retention: a reason exists to return after first use;
- trust: credibility, permissions, integrations, data access, or behavior change may block use;
- distribution: a repeatable path to the target user exists; and
- adoption: the proposed change alters useful behavior instead of adding unused surface area.

If evidence is weak, identify one cheapest signal and delay the scope that depends on it. If evidence is strong, name it and reduce the remaining validation step. Never turn lack of evidence into a fabricated market conclusion.
