# Greenfield MVP Plan

Produce one bounded MVP packet for the Architecture Gate. Read [the adapted upstream reference](references/upstream.md) before applying it.

Return:

1. one-sentence MVP outcome;
2. up to three essential user outcomes;
3. the single smallest useful slice;
4. explicit exclusions and deferred capabilities;
5. dependency-ordered conceptual slices;
6. effort ranges with assumptions rather than fixed promises;
7. the largest delivery risks; and
8. any one question that needs Matt `prototype` rather than more discussion.

Keep sequencing conceptual. Do not prescribe coding sessions, create Tickets, select an Implementation Lane, write production code, provision accounts, deploy, or present the packet as a Spec. Distinguish a planning packet from Matt `prototype`, which creates a throwaway runnable artifact to answer one narrow question.
